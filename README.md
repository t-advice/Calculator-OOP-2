# CalculatorOOP

A simple object-oriented calculator I  built in C#.  
This project demonstrates the basic principles of **Object-Oriented Programming (OOP)** — such as  Polymorphism and inheritance— using a simple calculator example.

---

## My Features

- Add, subtract, multiply, and divide numbers
- Object-oriented structure (Calculator class handles all operations)
- Basic error handling (division by zero)
- Console-based interaction

---

## OOP Concepts I Used

| Concept | Description | Example in Project |
|----------|--------------|--------------------|
| **Class** | Blueprint for creating objects | `Calculator` |
| **Object** | Instance of a class | `Calculator calc = new Calculator();` |
| **Encapsulation** | Keeping logic inside methods | `Add()`, `Divide()` methods |
| **Abstraction** | Hiding implementation details | User only calls methods, doesn’t see the logic |
| **Polymorphism (Optional Extension)** | Same method name, different behavior | Could extend later with method overloading |
